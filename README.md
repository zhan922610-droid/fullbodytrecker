# Full Body Tracker

Мобильный дневник силовых тренировок на русском языке. Приложение работает как PWA, хранит данные локально, поддерживает историю, перенос прошлых рабочих весов, таймер отдыха и резервные копии.

## Запуск на Windows

### Самый простой способ
1. Установи Node.js LTS с официального сайта https://nodejs.org/ (нужен только если хочешь использовать локальный сервер через npm).
2. Распакуй архив в удобную папку.
3. Открой терминал в папке проекта.
4. Запусти статический сервер, например:
   ```bash
   npx serve .
   ```
5. Открой указанный локальный адрес в браузере.

Для тестирования обычного интерфейса можно открыть `index.html` напрямую, но установка PWA и офлайн-кэш работают корректно через HTTP/HTTPS, а не через `file://`.

## Публикация через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи содержимое папки проекта в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохрани настройки и дождись публикации.
6. Открой HTTPS-ссылку на телефоне.

Если проект опубликован в подпапке репозитория, относительные пути `./` уже используются для основных ресурсов.

## Установка на телефон
- **Android / Chrome:** открой сайт → меню браузера → «Установить приложение» или «Добавить на главный экран».
- **iPhone / Safari:** открой сайт → «Поделиться» → «На экран Домой».

## Данные и резервные копии
История хранится локально в браузере на устройстве. Экспортируй JSON через **Настройки → Экспортировать данные**. На другом устройстве открой приложение и выбери **Импортировать данные**.

Важно: очистка данных браузера, приватный режим или потеря устройства могут привести к потере локальной истории. Экспортируй резервные копии регулярно.

## Возможности
- 3 дня Full Body с упражнениями из исходной программы.
- Один экран на упражнение и фиксация подходов.
- Автоперенос последних весов и повторений для каждого упражнения.
- Автосохранение незавершённой тренировки.
- История и графики тоннажа.
- Таймер отдыха.
- Специальные форматы Myo-Reps и дроп-сетов.
- Экспорт/импорт JSON.
- Офлайн-кэш и установка как PWA.
